Examples
========

Comprehensive examples are available in the ``examples/`` directory:

Core Module
-----------

* ``core_basic.py`` - Basic usage of core structures
* ``core_advanced.py`` - Advanced features

Builders
--------

* ``builders_bulk.py`` - Bulk structure generation
* ``builders_surface.py`` - Surface slab creation
* ``builders_alloy.py`` - Alloy generation
* ``builders_molecule.py`` - Molecular structure builders
* ``builders_defects.py`` - Defect creation
* ``builders_nanostructure.py`` - Nanostructure generation

Transformations
---------------

* ``transformation_geometric.py`` - Geometric transformations
* ``transformation_lattice.py`` - Lattice transformations
* ``transformation_chemical.py`` - Chemical transformations
* ``transformation_structural.py`` - Structural transformations
* ``transformation_composite.py`` - High-throughput transformation tools

Other Examples
--------------

* ``io_basic.py`` - File I/O operations
* ``workflow_basic.py`` - Workflow examples
* ``calculator_basic.py`` - Calculator usage
* ``storage_basic.py`` - Data storage
* ``symmetry_basic.py`` - Symmetry analysis
* ``config_basic.py`` - Configuration management

Running Examples
----------------

To run an example:

.. code-block:: bash

   python examples/core_basic.py
   python examples/builders_bulk.py
