Key Changes

AreaWhat HappensNew Files
CoreStrip from_file/to_file, graph, neighbors → analysis. Add protocols.py. Must not import io/storage/builders/transformation.1
AnalysisReceives graph.py + neighbors.py from core. Becomes the home for structure analysis.0
TransformationReceives defects, alloy modifiers, interface stacking, surface modification from builders. Add TransformationSpec + Registry.2
BuildersLoses defects/, alloy/, interface/, adsorbate. Keeps bulk/, surface/slab, molecule/, nanostructure/. Add BuilderRegistry. Internally depends on transformation for modification steps.1
IOAdd FormatHandler registry. Replace if/elif dispatch with table lookup. Move converters → adapters/. Move latex → export/.1
AdaptersNew package for pymatgen/ASE converters (from io/converters.py).1
ExportNew package for LaTeX table export (from io/latex.py). Presentation concern.1
StorageSplit into schema.py, codec.py, backend.py, memory_store.py, facade.py. Maggma file refactored as backend impl.4
ExceptionsNew top-level module with domain-specific exception classes.1

Dependency Rules (Enforced)

core — imports nothing from matsimpy except constants.py
transformation → core, exceptions, constants
builders → core, transformation (for internal modification steps), exceptions
analysis → core, exceptions
io → core, adapters, exceptions
adapters → core (lazy-import pymatgen/ase at use time)
export → core
storage → core (serialization), exceptions
